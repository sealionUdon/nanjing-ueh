# 南京城市生态系统健康评价（2020—2024）

本库复现南京五要素、27 项指标的年度物元评价。**用原文经典域不能直接得到完整的 25 项等级**：两项指标已更换口径。年度表并列报告两种阈值口径，避免把探索性的代理分级误称为文献标准。

## 一键运行

在仓库根目录使用 Python 3.12（实测 3.12.8），无需网络取数：

```powershell
python -m pip install -r requirements.txt
python src/evaluate.py
python -m unittest discover -s tests -v
```

## 数据来源与核对

- `data/indicators_2020_2024.csv` 由项目的 `南京数据表_27项_v5_20261127.csv` 按编号选取中文名、单位、方向、AHP 权重、五年原值、状态、数据出处和口径说明，原文件 SHA-256：`9ae687f25585b6990a2a01b19110156928122d79cebf77a0560f42ca16c4a9fb`。不填补缺测；新增 `exclude` 和用分号分隔的“假设年份”。年度量值来自南京、江苏统计年鉴、南京生态环境公报和卫健资料，逐行可追溯。`状态` 是指标级状态，不能据此断言每一年均为实测。
- `data/weights.csv` 的五组及全局 AHP 权重、`data/thresholds.csv` 的 27 行五级原始区间分别源自 Xie & Pu (2017), *Assessment of Urban Ecosystem Health Based on Matter Element Analysis*, Table 2、Table 3，DOI：`10.3390/ijerph14080940`。本地论文为 `文献/Jiangsu2017.pdf`；区间直接取自项目所存原文 XML 的第三张表，顺序为病态至优良。附加的“阈值策略”不是原文字段。
- X16、X23 整段排除，X23 的 2020 实测仍保留在输入中。27 项权重实际合计 1.0002；保留 25 项逐项合计 0.8923，因此用实际合计而不是 0.8921 归一化。排除项权重为 0。

## 如何解释等级

1. **仅原经典域**：只对仍使用 Table 3 阈值的 23 项计算。**25 项探索**：另纳入 X3（工业增加值能耗替代全社会 GDP 能耗）和 X13（排放强度，吨/万元，替代达标率，%）。仅对这两项用各自五年最小到最大值的五个等宽区间作相对分级，均为越低越好。该选择不是已核定的代理标准，样本极值和起止年会改变结果；用于趋势探索而非绝对健康评价。应优先取得同口径阈值或原指标数据。
2. 程序先按数轴排序区间，再按方向建立病态至优良的次序：正向从低到高，负向从高到低。不会把 Table 3 已降序的负向指标反转两次，也不会仅靠翻转方向把百分比换成强度。
3. 对区间 `[a,b]` 定义 `ρ=max(a−x,x−b)`，节域取五区间并集，记其距离为 `ρp`。区间内 `k=−ρ/(b−a)`，区间外 `k=ρ/(ρp−ρ)`（原文式 5–6）。观测越出整个节域时，按本项目约定截至最近端点，保留原观测并标示越界，不外推改善或恶化幅度。内部分界点同属相邻两级、关联度均为零，取较差等级；综合同分也按此顺序处理。
4. 年度五级关联度是当年参与项的加权平均（式 7），最大关联度对应年度等级。关联度可为负，不是概率，不要求五级之和为 1。组得分是组内重新归一化后五级关联度的最大值，代表对判定等级的支持度，**不是健康水平的线性分数**。可选 `src.fuzzy.membership` 以按等级排序的区间为输入，在相邻中心间线性插值，作为独立对照。
5. X25 的 2020 年 2.71‰ 为实测；2021—2024 沿用 2.71‰，仅为假设。输出按指标年标记 `is_assumed`。每种阈值口径都分别计算含假设值、剔除当年假设值两种情形，后者重新归一化总权重和组内权重，2020 不变。

## 输出与已知限制

- `outputs/scores_by_indicator.csv`：25×5 行，含原值、方向、采用的阈值策略、越界、假设标记、五级关联度与判定等级。
- `outputs/result_annual.csv`：5 年×2 种阈值口径×2 种假设情景，共 20 行，含实际项数、权重分母、五级关联度、综合等级及五要素得分和等级。
- `outputs/weight_check.csv`：全部 27 项的基础权重对照；敏感性计算的有效权重为该项原权重除以对应年度行的原权重合计。三表可重复覆盖生成。
- X7 人口密度、X21 道路面积的空间或人口分母待核对；X22 公交车辆不代表全部轨道运力；X26 床位范围比原指标宽；X27 按人/万人使用，保留原表单位注释。部分观测超过历史节域，截界会压缩年份差异。年度等级相同，不表示各指标不变，也不是对南京健康水平的独立验证。

## 推送到 GitHub 的步骤

本仓库仅在本地初始化，无远端。稍后在 GitHub 建立空仓库；HTTPS 令牌方式需要具备该仓库 Contents 写权限的 `GITHUB_TOKEN`。在受信任的终端安全提供令牌，不要写入脚本、仓库、远端 URL 或命令历史。PowerShell 示例（使用前替换占位符）：

```powershell
# 仅当网络需要代理时设置；地址、端口按实际配置
$env:https_proxy = 'http://代理主机:端口'
git remote add origin https://github.com/OWNER/REPO.git
git push -u origin HEAD:main
```

HTTPS 认证提示中输入 GitHub 用户名，密码处输入 `GITHUB_TOKEN` 的值；Git 不会自动读取同名环境变量。也可使用已配置的凭据管理器。直连无需 `https_proxy`；会话结束可用 `Remove-Item Env:https_proxy` 清理代理设置。
