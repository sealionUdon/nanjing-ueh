# 复现南京 2020—2024 年评价

## 环境与运行

使用 Python 3.12（仓库实测 3.12.8）。输入已在 `data/`，计算与测试不需联网取数。首次安装依赖需可用的软件包源或本地缓存。以下为 Windows PowerShell 命令，从含 `README.md` 和 `requirements.txt` 的仓库根目录执行，无需激活虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src/evaluate.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

macOS/Linux 将 `python` 换为对应的 `python3.12`，后三行的解释器换成 `./.venv/bin/python`。终端显示年度等级透视表；完整精度看 CSV。再次运行会覆盖三份同名输出，不修改输入。测试检查权重、方向与区间边界以及情景汇总。

## 如何核对输出

| 文件 | 每行的含义 | 首要核对项 |
|---|---|---|
| `outputs/scores_by_indicator.csv` | 每个保留指标每年一行，共 125 行 | 以「编号＋年份」定位；「值」是未截界的观测，后列给出方向、阈值策略、越界、`is_assumed`、原权重、五级关联度和判定等级。 |
| `outputs/result_annual.csv` | 每一「年份＋阈值口径＋情景」一行，共 20 行 | 勿仅按年份取第一行；看参与项数、假设值项数和原权重合计，再比较五级关联度。最大者决定综合等级；组得分是组内加权后的最大关联度。 |
| `outputs/weight_check.csv` | 全部 27 个指标的基础权重对照 | X16、X23 的归一化权重为零；基础权重不能替代敏感性情景的有效权重。 |

对照示例：年度表筛选「2024／25项探索／含假设值」，应有 25 项、1 项假设值，判定优良；仅切换到「剔除假设值」，应有 24 项、0 项假设值，仍判优良。到指标年表筛选同年 `is_assumed=True`，对应 X25。

## 常见问题

- **导入 pandas 失败或版本不一致**：用运行脚本的同一解释器执行 `-m pip show pandas numpy openpyxl`。以 `requirements.txt` 锁定的版本为准（pandas 3.1.1、NumPy 2.5.4、openpyxl 3.1.5）；不要只升级其中一个包。若提示找不到分发包，先核对 Python 版本和软件源。
- **找不到脚本或输入**：命令中的相对路径基于当前目录；程序内的 `data/`、`outputs/` 则相对于脚本所在仓库。从其他目录启动时用脚本的完整路径，带空格的路径加引号，勿只复制 `evaluate.py`。
- **提示编号、权重、经典域或缺测校验失败**：检查三表编号唯一且齐全，跨表名称、方向和排除标记一致；区间分隔符为 `–`，假设年份用英文分号。不要把缺失填成零来绕过校验。
- **Excel 显示乱码或写入被拒**：输出编码是 UTF-8 BOM；按 UTF-8 导入，运行前关闭占用 CSV 的工作簿。核对完整精度请读原 CSV，不要将表格软件的显示舍入回写。
- **负关联度也能判优良？** 比较同年五列的相对大小，不以零为合格线；舍入后看似相等时以原始精度为准。解释和限制见[结果解读](结果解读_2020_2024.md)。
