# 数据说明

`data/` 下三张 CSV 均以唯一的「编号」X1—X27 连接，不靠行号匹配。数值核对分三层：观测值和指标年标记看 `outputs/scores_by_indicator.csv`，基础权重看 `outputs/weight_check.csv`，实际计入哪些口径、项数和权重分母看 `outputs/result_annual.csv`。被剔除的原始记录只在输入观测表中保留。

## 年度观测：`indicators_2020_2024.csv`

来源为项目底表 `南京数据表_27项_v5_20261127.csv`（校验摘要见根目录 README）。统计依据以各行「数据出处」为准，包括《南京统计年鉴》《江苏统计年鉴》、南京市生态环境公报及卫健部门资料；年鉴版本年与观测年不能混用。

| 字段 | 含义与读取方式 |
|---|---|
| 编号、名称 | 稳定连接键与展示名称；名称沿用原体系时，实际覆盖范围以口径说明为准。 |
| 单位、方向 | 年值的计量单位；正表示越高越好，负表示越低越好，指本模型的排序而非普遍价值判断。百分数按表中数值读，不再除以 100。 |
| 原权重 | 指标全局 AHP 权重，与权重表一致。 |
| 2020、2021、2022、2023、2024 | 五个年度原量纲值，不是得分。排除项仍保留原值或缺失原因文本，不以零替代。 |
| 状态、exclude | 前者为整项资料状态（含待核对），后者为全期排除布尔值；不能用状态代替年度实测标记。 |
| 假设年份 | 英文分号分隔的年份；空白表示未标记假设，不保证该项有完整观测。 |
| 数据出处、口径说明 | 前者标明年鉴版本、表号或公报；后者记录统计范围、分子分母、换算及与原指标的差异。 |

**两项代理的换算**（分子分母来源取本表相应行，结果与指标年输出的「值」核对）：

- **X3 单位工业增加值综合能耗**：市级缺全社会能源消费总量，以全部工业企业综合能源消费量和工业增加值替代全社会能耗和 GDP。能耗（吨标准煤）÷〔工业增加值（亿元）×10,000〕即吨标准煤/万元。例如 2020 年 37,944,934 ÷（4,095.86 × 10,000）≈ 0.926。分子取南京统计年鉴工业能耗表，分母取 2025 版表 2-2 修订序列；负向，不宜与原全社会口径拼接。
- **X13 工业废水排放强度**：原达标率停止发布后，改取南京统计年鉴 2025 版表 16-8 工业废水排放量和表 1-5 GDP。排放量（万吨）×10,000 ÷〔GDP（亿元）×10,000〕＝吨/万元GDP，两处换算因子相消。2020 年以 12,796.54 万吨作分子，结果为 0.864 吨/万元GDP。原达标率为正向百分比，新强度为负向；两者不能通过单位换算互推。

**缺失与假设**：X16 环境污染治理投资总额占GDP比重五年均为「数据缺」；市级无同口径全社会治理投资，财政环保支出不能代替。X23 城镇登记失业率保留 2020 年实测 1.71%，此后为「待获取」，不混用调查失业率。为使各年可比，两项均设 `exclude=true`，包括 X23 的 2020 年；不插补，不进入指标年表。其余参与项必须是有限数值。

X25 5岁以下儿童死亡率五个年值均写 2.71‰，但 2020 年为南京实测，后四年缺市级公布值，不用江苏省值替代。将 2020 年水平作为假定上界原值延续，并非已证实的上界。输入「状态」为「已确认（假设值）」，「假设年份」为 `2021;2022;2023;2024`；输出 `is_assumed` 在 2020 年为 `False`、之后为 `True`。「剔除假设值」仅删除当年标记者，因此两情景在 2020 年相同。

## 权重与分组：`weights.csv`

来源：Xie & Pu（2017），*Assessment of Urban Ecosystem Health Based on Matter Element Analysis*，Table 2（DOI：`10.3390/ijerph14080940`）。「编号、名称」对应观测表；「分组」为所属五要素；「原权重」为全局权重而非组内占比；「方向」取实际使用的指标方向；`exclude` 与观测表一致。「归一化权重」和排除标记是项目处理结果，不是原文权重。

按 `outputs/weight_check.csv` 逐项求和，原权重合计 1.0002；扣除 X16 的 0.0660 和 X23 的 0.0419 后，分母是 **0.8923**。基础归一化权重＝原权重÷0.8923，排除项为零。年度情景按实际参与项重算，不能继续套用基础分母；例如 2024 年探索口径剔除 X25 后分母为 0.8563（`outputs/result_annual.csv`）。各要素单独求组内分母。所有编号须有权重，无缺项回填机制。

## 等级区间：`thresholds.csv`

来源为同一论文 Table 3。「编号」连接其他表；「病态、一般、中等、良好、优良」五列保留原量纲经典域，每格为 `下限–上限`；「阈值策略」是本项目新增字段。`Table3` 表示直接使用原区间；`样本等宽` 仅用于 X3、X13：保留原五列供溯源，**实际计算不用这两行的经典域**。程序对每项五年最小值至最大值等宽分为五段，再按负向从高到低对应病态至优良。「仅原经典域」直接排除这两项，不把旧阈值用于代理指标。

区间须完整、连续且宽度为正；不对缺失阈值插值。越出全部区间的观测在计分时截到最近端点，原值不改并标记「越界」；共同边界同分取较差等级。X7 的「城区」实际按全市行政边界，X21 铺装范围与人口分母待核对；X22 不含轨道，X26 实际含基层等卫生机构，X27 应按人/万人读。
